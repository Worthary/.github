# Worthary

**The library of open source worth using.**

Worthary helps people and AI agents discover useful open source projects, understand what they do, what they require, and whether they are worth starting with.

[Visit Worthary →](https://worthary.com/)

## What Worthary helps you answer

Every project on Worthary is presented around a few practical questions:

- **What does it actually do?**
- **Can I use it?**
- **What does setup and ongoing maintenance involve?**
- **Is it reliable and worth starting with now?**

Worthary turns technical project information into clear, practical guidance so that useful open source software is easier to evaluate before you invest time in it.

## How Worthary works

Worthary discovers projects from GitHub, project authors, curators, practitioners, and the wider open-source community.

Each listed project is reviewed before publication. Worthary looks at first-party documentation and other relevant public evidence, then organizes the findings into structured project profiles focused on:

- real-world use cases;
- setup requirements;
- ongoing maintenance;
- licensing and usage conditions;
- important limitations and prerequisites;
- evidence and source traceability.

The goal is to make open-source projects easier to understand for both people and AI agents.

## For people and AI agents

For people, Worthary reduces the amount of GitHub terminology and technical documentation you need to interpret before deciding whether a project fits your needs.

For AI agents, Worthary provides clearer and more structured context about what a project does, who it is suitable for, and what using it actually requires.
